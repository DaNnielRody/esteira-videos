# Esteira de Vídeos

Esteira de vídeo automática: gera vídeos a partir de roteiros já prontos usando bibliotecas de Python.

## Sobre

Pipeline que recebe roteiros prontos e os transforma em vídeos renderizados de forma automatizada, sem intervenção manual.

- Bibliotecas de renderização de vídeo (a definir)
